**HALDER** (हलधर) — это высокопроизводительная сельскохозяйственная платформа корпоративного уровня, объединяющая фермеров и сельхозпроизводителей напрямую с розничными покупателями, оптовиками и предприятиями общепита по всей Индии. Устраняя цепочки посредников, HALDER обеспечивает фермерам максимальную рентабельность, а потребителям — утренний сбор свежих продуктов в радиусе до 300 км.

---

## 🌾 Основные модули системы

### 1. Покупательский опыт
- **Гиперлокальный поиск:** Поиск хозяйств в радиусе 300 км с использованием формулы гаверсинусов.
- **Свежесть и прозрачность сбора:** Отметки утреннего сбора, органик-сертификаты и прослеживаемость от поля до стола.
- **Умная корзина:** Поддержка прямой доставки от фермера, рефрижераторной логистики и самовывоза.
- **Безопасное вручение:** Подтверждение доставки через одноразовый OTP-код и отслеживание статуса.
- **Чат с фермером в реальном времени:** Двусторонние WebSockets с поддержкой перевода на 5 языков (английский, хинди, панджаби, бенгали, маратхи).

### 2. Бизнес-кабинет фермера
- **Профиль хозяйства и земли:** Структура почвы, ирригация, сертификации и график сбора урожая.
- **Управление каталогом и склад:** Пересчет единиц измерения (кг, пучок, ящик, литр), сезонные переключатели доступности.
- **Рыночная аналитика Mandi:** Данные котировок APMC, динамика базовых цен и выгрузка отчетов в CSV.
- **Финансовая отчетность:** Автоматический расчет валовой выручки, вычет 10% сервисного сбора и журнал выплат.

### 3. Логистика и автопарк Kisan
- **Регистрация перевозчиков:** Проверка транспортных средств (мото, фургоны, рефрижераторы, тракторы) и водительских удостоверений.
- **Телеметрия в реальном времени:** Контроль допустимого диапазона координат (-90 <= lat <= 90, -180 <= lng <= 180) и проверка прав доступа пользователя.
- **Аналитика доставок:** Расчет фактического времени в пути и процента своевременных доставок на основе БД.
- **Прямая фермерская доставка (Kisan Direct):** Доставка силами самого производителя с 0% комиссии.

### 4. B2B Опт и контрактное фермерство
- **Оптовые запросы (RFQ):** Минимальный объем заказа (MOQ), скидки от объема и расчет стоимости.
- **Форвардные контракты:** Соглашения с графиком поэтапных поставок.

### 5. Безопасность и администрирование
- **Разграничение прав (RBAC):** Изоляция ролей покупателя, фермера, курьера и администратора.
- **Защита от IDOR:** Предотвращение несанкционированного доступа к заказам и координатам.
- **Верификация KYC:** Проверка документов фермера и прав на землю.
- **Журнал аудита:** Неизменяемый журнал критических действий.

## 🛠️ Стек технологий

- **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React
- **Мобильное приложение:** Capacitor 8 Android SDK
- **Бэкенд:** Node.js (>=22.5.0), Express.js, TypeScript
- **База данных:** SQLite 3 (`node:sqlite` DatabaseSync) в режиме WAL
- **Связь в реальном времени:** WebSocket (`ws`)

## 🚀 Запуск проекта

```bash
# Установка зависимостей
npm install

# Инициализация и сидирование БД
npm run server:seed

# Запуск бэкенда (http://localhost:5000)
npm run server

# Запуск фронтенда (http://localhost:5173)
npm run dev
```
